# b0 辨识移植到 MATLAB R2018b（无 C 编译器，走 MATLAB Function）

目标机只有 R2018b，且不支持 C 编译，因此**只走 `b0_ident_m.m` + `build_foc_m.m`**
这条路。C 版（`b0_ident.c` / `b0_foc2.slx`）仅作为参考基准，不要拷过去。

**分步操作见同目录的 `移植步骤_R2018b.md`：准备 → 自检 → 跑通算例 → 接进自己的模型 → 验证 → 排错。**

## 1. 为什么必须换实现

| 约束 | 后果 |
|---|---|
| C Caller 块 R2019b 才引入 | R2018b 没有，`b0_foc2.slx` 无法使用 |
| Simulink 不向下兼容 | R2023b 保存的 .slx 在 R2018b 打不开 |
| 目标机无 C 编译器 | 无法构建 MEX / 仿真目标 DLL |

MATLAB Function 块是纯 .m，正常仿真由解释执行，**不需要任何编译器**。

## 2. 要拷哪些文件（只有这 5 个）

| 文件 | 作用 |
|---|---|
| `b0_ident_m.m` | 算法本体（粘进 MATLAB Function 块） |
| `build_foc_m.m` | 一键建 `b0_foc_m.slx`（FOC + RCESO + MATLAB Function） |
| `run_foc_m.m` | 单独跑已建好的模型、输出闭环终值 |
| `test_b0_m.m` | **解析自洽测试，先跑这个** |
| `README_2018b.md` | 本文件 |

**不要拷**：`*.slx`（版本不兼容，必须就地重建）、`*.mexw64`、`*.slx.r*`、`slprj/`。

## 3. 目标机三步

```
1) test_b0_m          % 自检：三个用例都应是 0.000% 误差
2) build_foc_m        % 建模型并自动跑 130 s
3) type out_f2s.txt   % 看闭环终值
```

**第 1 步的预期输出**（R2023b 实测，R2018b 应完全一致，都是双精度）：

```
=== b0_ident_m 解析自洽测试（24 个 burst，5 s 周期，冻结取末 4 次）===
用例                    b_true      b_est        误差
正弦 T=1.00<0deg        400.0    400.000     0.000%
正弦 T=0.95<+5deg       400.0    400.000     0.000%
正弦 T=0.90<-10deg      400.0    400.000     0.000%
结论：全部通过（|误差| < 0.05%）
```

**第 2 步的预期输出**：

```
SIM_OK b0=530.61 w=600.00 du_max=0.1180 (真值 536.40)
b0轨迹: 531@20s 531@40s 531@60s 531@80s 531@100s 531@120s 531@140s
```

b0 ≈ 530.6、误差 −1.08%，与 C 版 530.61 一致到 0.01%。转速 600 rpm、注入幅值 0.1180 pu。

## 4. 时序（与 C 版一致，改动过）

| 项 | 值 |
|---|---|
| burst 周期 | **5 s，从 burst 起点计**（24 个 burst 恰好 120 s） |
| 单个 burst | 前 0.2 s 不注入、后 0.2 s 注入（各 200 拍） |
| 预热 | 前 3 个 burst 经 τ=kp/50 低通采纳，不直接跳变 |
| 冻结 | 第 24 个 burst 结束（约 115.4 s）取末 4 次均值，之后周期 3600 s |
| 时基 | 整数拍计数（uint32 → 在 .m 里就是 double 计数），**不用秒数累加** |

## 5. 端口（采样 1 ms）

| 端口 | 方向 | 单位 | 说明 |
|---|---|---|---|
| iq | in | pu | 实测 q 轴电流（A ÷ IBASE） |
| u | in | pu | 控制量，**须与 iq 同刻**（FOC 里取 u(k-1)） |
| omega | in | rpm | 转速，仅诊断 |
| e1 | in | pu | 观测器误差 y − z1 |
| v | in | pu/s | 重复内模状态 |
| b0 | out | 标幺 | 初值 400，冻结后保持不变 |
| du | out | pu | 注入量，内部生成，需叠加到控制量上 |

## 6. 定标点（换电机只改这里）

| 参数 | 位置 | 说明 |
|---|---|---|
| 注入频率 | `f_inj = 65` | 须 5 Hz 整数倍，且 `f_inj*dT*nseg` 为整数 |
| 注入幅值 | `amp = 0.118` | 占比 ≤ 0.25 |
| 初值/限幅 | `b0_init=400`, `b0lo/b0hi=200/800` | 填控制器标称值 |
| 观测器带宽 | `wo = 500` | 必须与模型里的 ESO 一致 |
| 转速环增益 | `kp = 75.36` | 决定低通 τ=kp/50 |

## 7. 已知的坑（都踩过）

1. **MATLAB Function 块里不能有顶层 `error()` 断言**。放了会报
   “没有完全确定其输出 'b0out' 的维度”，整个模型无法 update/sim。频率-段长相干性检查
   因此只留注释与 `cyc_nseg` 变量。**这条正是本模型一度无法重建的原因。**
2. **别拷 .slx**：R2023b 存的模型在 R2018b 打不开，必须在目标机跑 `build_foc_m` 重建。
3. 若 `add_line(...,'autorouting','on')` 在老版本报参数不识别，把 `,'autorouting','on'` 去掉即可。
4. `Callee` 一侧的 `b0_res_t` 总线对象在这里**完全不需要**（那是 C 版的事）。
5. 目标机若勾选“加速/代码生成”模式才需要编译器；**正常仿真不需要**。

## 8. 与 C 版的等价性

在 R2023b 上把两版喂同一条 130 s 闭环记录流逐点回放（`cmp2.m`）：

| 项 | 结果 |
|---|---|
| 末值 | C 530.6365 / MATLAB 530.6365 |
| 全程最大相对差 | 9.2e-5 |
| 注入波形逐点差 | 3.2e-3 pu（256 点 LUT 相对 sin 的相位量化） |

迁移到 R2018b 后不必再比这个——先跑 `test_b0_m`（算术）与 `build_foc_m`（闭环）两步即可。
