## 3. 第三步：接进你自己的模型（核心）

### 3.1 放块
- 拖一个 **MATLAB Function** 块
- 双击打开编辑器，把 `b0_ident_m.m` 的**全部内容**粘进去
- 粘贴后端口自动变成 5 进（iq, u, omega, e1, v）2 出（b0, du）

### 3.2 采样时间
- 块参数里的 Sample Time 填 `1e-3`，或让整个模型就是 1 ms 单速率
- **算法按 1 ms 写死**：注入频率、段长 200 拍、burst 5000 拍都按 1 kHz 折算。若不是 1 ms，全盘重算

### 3.3 五个输入怎么接

| 输入 | 接什么 | 注意 |
|---|---|---|
| `iq` | 实测 q 轴电流 | 单位 **pu**：A ÷ IBASE（本机 IBASE=6.3069） |
| `u` | 控制量 | **必须是上一拍**的值（$u(k-1)$）。FOC 里 $i_q(k)$ 响应的是 $u(k-1)$，送同拍会引入 23° 相位偏差 |
| `omega` | 转速 | 目前只累加、不参与计算，喂 0 或标称值都行 |
| `e1` | 观测器误差 $y-z_1$ | **不是**控制误差 $\omega_{ref}-z_1$；用错会让 $z_2$ 积分发散 |
| `v` | 重复内模状态 | 来自 RCESO 观测器；没有重复内模的系统不能直接套用本算法 |

### 3.4 两个输出怎么接

- `b0` → 观测器/控制律里的 $b_0$。**加一个 Unit Delay（初值填标称 b0）**再送回去，打断代数环
- `du` → 叠加到转速环输出的**电流指令**上（本模型接在 `u = (u_{loop})/\omega_{ref}` 之后、电流环之前）

### 3.5 只改这几个数（文件顶部「顶层可调参数」）

| 参数 | 填什么 |
|---|---|
| `dT` | 1e-3（与 3.2 一致） |
| `f_inj` | 65（5 Hz 整数倍；且 `f_inj*dT*200` 须为整数） |
| `amp` | 0.118（上限 0.25） |
| `b0_init` | 你控制器里的标称 $b_0$ |
| `b0lo/b0hi` | 200/800（约 0.5×/2× 标称） |
| `wo` | **必须**与你模型里的 ESO 带宽一致（β1=2ωo、β2=ωo²） |
| `kp` | **必须**与你转速环的 kp 一致（决定低通 τ=kp/50） |

## 4. 第四步：接好后看什么（验证清单）

跑 130 s，用 Scope 看 `du` 与 `b0`：

| 检查项 | 期望 |
|---|---|
| `du` 形状 | 每 5 s 一个包：前 0.2 s 静默、后 0.2 s 满幅 65 Hz 正弦，幅值 ±0.118 |
| `b0` 收敛 | 前 3 个 burst 经低通平滑爬升，约 10–20 s 内进入 ±3% |
| 冻结 | 第 24 个 burst 结束（约 **115.4 s**）取末 4 次均值后不再变化 |
| 冻结后 | `du` 恒为 0，转速回到设定值，长期运行不受影响 |
| 精度 | 与离线真值 $b=k_t I_{BASE}/(J\omega_{ref})$ 比对，误差 ≤ **1.5%** 视为正常（本算例 −1.08%） |

## 5. 常见故障排查

| 症状 | 首先查 |
|---|---|
| `b0` 一直不动 | 模型采样时间是否 1 ms；`du` 有没有真的叠到控制量上；块是否被条件执行分支吞掉 |
| `b0` 越跑越偏、不收敛 | `u` 是否延迟一拍；`e1` 是否误用了控制误差 |
| 模型无法 update，报 “没有完全确定其输出 'b0out' 的维度” | 块脚本里是否被加了顶层 `error()` 断言（**不能有**） |
| 建模型报找不到 `b0_ident_m.m` | 两个文件不在同一目录；`build_foc_m` 取自身所在目录，必须同放 |
| 注入幅值远大于 0.118 | 你用的是 C 版算法或旧文件；本 MATLAB 版无 LUT，注入由 `amp` 直接给定 |
| `add_line(...,'autorouting','on')` 报不识别 | 老版本去掉该参数 |

## 6. 已知限制（写进设计说明里）

1. **注入频率须为 5 Hz 整数倍**，且 `f_inj*dT*200` 为整数，否则两段窗不相干
2. **辨识窗口固定 24 个 burst × 5 s**，约 115.4 s；之后冻结，周期 3600 s 才重新评估
3. **冻结后不再更新**：若负载惯量会变（联轴、换挡），缩短 `nident` 或把周期改小
4. **算法绑定 RCESO 观测器结构**（ESO + 重复内模）；换观测器需重推反演式
5. 注入期间转速有纹波（本算例峰峰约 337 rpm）；burst 只有 0.4 s、总共 120 s，对长期运行无影响，暂不补偿

---

## 7. R2018b 特有注意

- 模型**必须在目标机就地重建**（`build_foc_m`），任何 R2023b 存的 .slx 都打不开
- MATLAB Function 块里的复数运算在 R2018b 支持仿真；若目标机报复数相关错误，用 `b0_ident.c` 的实部/虚部标量写法改写（C 版本就是那么写的）
- 块里不能有顶层 `error()`（见第 5 节）
- 只有勾选“加速/代码生成”模式才需要编译器；正常仿真不需要
