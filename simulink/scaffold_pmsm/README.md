# 厂家模块 FOC + b0 辨识（诊断记录）

## 现象

给 `b0_ident_m` 加了第三个输出 `bq`（逐窗原始估计），实测：

| 量 | 值 |
|---|---|
| bq 原始估计 | **1.0 – 2.3** |
| 真值 | 536.4 |
| 比值 | **≈ 1/300** |

放开限幅（b0lo=1）后能看到真实值，此前"塌到 200/300"都是被限幅压住的表象。

## 含义

`bq = |Δd̂ + b0·Δu| / |Δĩ|` 只有真值的 1/300 ⇒ **分子几乎完全抵消**：
`Δd̂ ≈ −b0·Δu`，即 ESO 的扰动估计里**已经包含了注入项**，
于是"Δd̂ + b0·Δu"相消，只剩下噪声级残差。

## 最可能的原因

1. **ESO 的 u 接的是注入后的电流指令**（u+du），而不是注入前的 u
   —— 这样 ESO 内部 b0·u 已经抵消掉注入的电流，d 里不再含 b·du
2. 或 ID 块的 u 输入与 ESO 的 u 输入不是同一个时刻的量（执行顺序/采样）

## 下一步

1. 核对 SL 里 ESO 的 u 项：必须是**注入前**的 u，且与送 ID 的 u 同一拍
2. 若确认，修正后重跑；预期 bq 回到 500 附近
3. 再做离线分解（Δd̂ 与 Δĩ 各占多少）确认
