# 厂家模块 FOC + b0 辨识（诊断记录）

## 分解输出（b0_ident_m 新增 3 个诊断口）

第一窗实测（b0v=536.4 正确、注入已到达电流）：

| 量 | 实测 | 期望 |
|---|---|---|
| |Δu| | 0.097 | ≈0.118 |
| |Δĩ| | 0.096 | ≈0.118 ✓ |
| |Δd̂ + b0·Δu| | **0.799** | 536.4×0.096 ≈ **51.5** |

⇒ **Δd̂ ≈ −51 ≈ −b0·Δu**：ESO 的扰动估计把注入看成**反号**的扰动。

## 结论

注入确实进了电流（Δu≈Δĩ），但 ESO 的 d̂ 把注入项抵消成了负号，
导致分子只剩 1.5%。这不是数值问题，是**符号/口径**问题：
ESO 的 `b0*u_act` 项与实际对象 `ẏ = b·u` 的注入响应方向不一致。

## 下一步（唯一需要做的实验）

**开环注入测符号**：固定电流指令 u0 + 正弦注入 du（不走速度环），
观察转速 65 Hz 分量相对 du 的相位：
- 若同相 → ESO 模型符号对，问题在别处
- 若反相 → 确认 ESO 的 u 项或 y 的符号反了
