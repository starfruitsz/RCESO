# 厂家模块 FOC + b0 辨识（诊断）

## 本轮两个重要修正

1. **MATLAB Function 块原来跑在基速率 1e-5（100 kHz）**，不是设定的 1 kHz / 20 kHz！
   必须用 `ch.ChartUpdate='DISCRETE'; ch.SampleTime='1e-3'` 设置（`set_param` 不认）。
   ——这解释了 burst 周期只有 0.25 s（应为 5 s）等一切异常。
2. **ESO 的 u 必须用注入后的 u_act = u + du**（用户指出）：幅频特性看的是输入 u，
   不是预注入值。反演里的 u 也一并用 u_act。
